# PLAN-032 公网中继切换端口验证

- 编写时间 2026-11-24 12:03（Asia/Shanghai）
- 源码基线 `fcbbbc7`
- 目标是从 `118.193.40.160` 的 `8000–8009` 中找出可用于 Android 与目标 Mac 公网联测的端口。
- 当前中继监听 `*:9432`，云主机本地 TLS 握手成功。公网探测 `9432` 超时，云主机网卡只捕获到了同一来源对 SSH 端口的 SYN。

## 测试步骤

1. 对照云主机监听列表和公网探测结果。选择空闲的 `8001` 启动临时实例，复用已部署的 v4 中继二进制和证书，使用单独的设备登记目录。
2. 在云主机的内网地址验证该实例的 TLS 握手。以 SSH 端口作为对照，抓取云主机网卡上从本机发来的 TCP 初始握手，对公网 `8000–8009` 逐个复测。从目标 Mac 同时确认 `8001` 的公网可达性。
3. 如果某个端口能从公网建立连接，用该入口继续 Mac 注册和 Android 配对，核对实际音频链路。如果探测均未到达云主机，停止临时监听，记录当前入站限制和继续联测所需的规则。

## 依据

- 局域网联测与公网超时记录见 `docs/dev/PLAN-031-android-mac-joint-test-OUTCOME.md:15`。
- 云端部署与客户端 TLS 端口配置见 `server/DEPLOY.md:227` 和 `server/DEPLOY.md:247`。
- 计划自查确认 `8000` 已有回环监听，`8001` 在核对时空闲。用实际 TLS 服务和 SYN 抓包同时验证云主机与公网入口。
