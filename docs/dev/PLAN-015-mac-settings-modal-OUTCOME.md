## 实施内容

### docs/ui-design/v3/mac.html（主改动）

1. **首页第二卡拆分**（原 `CONNECTION SETTINGS · 中继服务器` 卡，含两个常驻输入框 + 保存按钮）：
   - 新 `RELAY SERVER · 中继服务器` 单行只读卡（`mac.html:177-190`）：wifi 图标 + 状态行（未连接/已连接地址+标签）+ RTT + 「修改」按钮；整卡可点，悬停边框高亮为琥珀系（`.srvcard`）。
   - 新 `AUDIO OUTPUT · 音频输出` 卡（`mac.html:192-212`）：原音频说明行、输出下拉、电平表、状态行原样迁出，内容未变。
2. **连接设置弹窗**（`mac.html:243-264`）：遮罩 `.ovl` + 对话框 `.modal`，含服务器地址/设备名输入（复用 `.field`）、错误提示行 `.merr`、说明文字、取消/保存设置按钮；CSS 复用现有 tokens 未新增色板。
3. **JS**（`mac.html:336-370` 附近）：
   - `openCfg()`（打开回填当前生效值、清错误）/ `closeCfg()`；×、取消、点击遮罩、Esc 四条关闭途径（Esc 仅弹窗打开时生效）。
   - 保存逻辑平移 V3.2 行为：`host:port` 正则校验，失败在弹窗内红字提示且不关弹窗；成功更新地址/设备名，未连接仅记日志，已连接自动断开重连；保留「地址未变化，仅设备名更新」提示；成功后关闭弹窗。
   - `connect()`/`disconnect()` 状态行文案同步：指向弹窗而非已删除的首页表单；`disconnect()` 增加未配置空态分支（`serverAddr` 为空时显示「未配置服务器 · 点击本卡填写服务器地址」）。
4. 清理拆卡后失效的 `.hr` 死样式；页首 tip 增加弹窗入口说明。
