## 当前阻塞

本次探测的 SYN 未到达云主机网卡。机器识别的平台为 UCloud，地域与可用区为 `hk` 和 `hk-02`。主机的 UFW 为 inactive，iptables INPUT 策略为 ACCEPT。下一步需要到对应弹性公网 IP 绑定的外网防火墙，核对入站 TCP 规则、规则来源范围和绑定关系。建议继续用本轮验证过的空闲端口 `8001`。[UCloud 外网防火墙说明](https://docs.ucloud.cn/unet/introduction/Overview/Firewall)

当前会话可通过 SSH 查验云主机，控制台会话和 UCloud API 配置均不可用。公网新入口和 Android 配对等待云端入站条件满足。
