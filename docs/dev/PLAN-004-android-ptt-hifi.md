## 二、改动方案

### A. 总览页 docs/ui-design/v2/index.html（小改）
- Android 主界面 `.pttzone`：删除装饰性 `.gbar`，缩小 `gap`，使 PTT 钮下缘贴近手机底部（约一指宽安全边距），与高保真稿一致。
- Android 列标题加"高保真稿"链接指向新文件。

### B. 新建高保真页 docs/ui-design/v2/android-ptt.html（核心交付）
单屏、自包含、无外部依赖，延续 v2 对讲机控制台暗色语言（琥珀主色/绿=传输中），保真度提升点：
- 真实手机外壳：挖孔摄像头、高光边框、屏幕噪点纹理、手势条。
- 拟真状态栏：时间 / 信号 / Wi-Fi / 电量（CSS/SVG 绘制）。
- 连接状态行：LED + "已连接 · MacBook-Pro"（说话前必须知道连着谁，判为相关）。
- 中央实时波形：待机静止刻度；按住时律动 + 计时器（mm:ss）。
- PTT 主钮：直径约 168px，锚定底部（距底 ≈28px），按下缩放 + 绿色辉光 + 扩散环，松开即停。
- 交互：pointerdown/up/leave 完整模拟"按下即传、松开即停"。
