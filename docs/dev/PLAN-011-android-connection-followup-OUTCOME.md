# PLAN-011 实施结果：Android 手机无法连接修复

实施日期：2026-08-28
基线提交：`d029e7da977ec246c8b00e6f1fe41dd4a8ee24d3`
对应计划：[PLAN-011-android-connection-followup.md](PLAN-011-android-connection-followup.md)

## 1. 用户意图

用户的真实问题不是继续增加输入项，而是：在当前 v3 新设计下，Mac Tauri 已经能连接 server，Android 输入 Mac 配对秘密后却没有进入有效连接流程，且失败原因不可见。本次按当前设计处理，不为旧客户端流程增加兼容路径：Android 只输入 Mac 配对秘密，服务器证书由客户端内部 TOFU 管理。

## 2. 实施内容

### Android 连接触发与状态

- 主页面新增设备后立即清除手动停止标记并自动启动连接。
- 设置页新增、修改或删除当前设备后，自动切换到最新激活设备；删除最后一个设备时停止服务。
- 服务新增 `ACTION_RESTART`，在服务内部停止旧 relay、等待线程退出后再启动新连接，不依赖固定延时。
- 配置、认证、网络、TLS、麦克风初始化和启动失败均保留中文错误状态；正常停止显示“已停止”。
- Android 13+ 通知权限不再阻断录音连接，启动前只检查麦克风权限。

### 网络与协议

- 服务器地址统一接受 `rv://host:port`、`host:port` 和省略端口的主机地址，默认端口为 `9432`，并处理带括号 IPv6。
- Android 继续发送 v3 `role=phone`、`proto=3` 和规范化秘密的 SHA-256 hex，与当前 server/Tauri Mac 字段一致。
- 首次 TLS 握手自动建立内部 TOFU；已保存证书变化会显示明确的指纹不符错误，不会被当作普通网络错误无限重连。
- 停止时关闭 TLS socket、连接中的原始 TCP socket，并中断/有限等待 relay 线程。
- 通过连接代次隔离旧 relay 和旧采音线程的延迟回调，防止切换设备后旧状态覆盖新状态或旧线程向新连接发送音频。
- 采音线程固定创建时的 relay 实例，避免旧线程在切换窗口重新读取到新连接。
- 错误停服后仅在状态条、设备操作或设置保存等明确用户操作下重试，避免后台自动覆盖错误原因。
- relay 自动重连时发送链路绑定连接序号，掉线会先使采音代次失效，避免旧采音线程跨重连写入新 socket。
- 发送音频时同时固定已检查的 TLS socket，避免检查与写出之间的重连窗口误写入新连接。
- 前台麦克风服务启动被系统拒绝时保留明确错误；当前设计文档同步说明不兼容旧 `?f=` 配置参数。
- 服务重启和对端掉线时会释放 `AudioRecord` 并有限等待旧采音线程，减少新连接抢占麦克风的竞态。
- 旧采音线程的麦克风异常只有在代次、relay 和录音实例均仍匹配时才会停止当前服务；前台服务运行时异常会显示为启动错误。
- 设置页删除当前设备且服务已停止时返回主页面，由主页面继续处理剩余设备的自动连接。

### 多设备存储

- 删除设备时正确提交新的设备列表和激活设备 ID。
- 删除当前设备后优先激活剩余设备；没有设备时服务进入停止状态。

## 3. Review 结果

实施后复核发现并修复了以下问题：

1. 主线程队列中旧 relay 的回调可能晚于设备切换执行，已通过连接代次二次校验解决。
2. 旧采音线程在切换窗口可能拿到新 `client`，已增加代次和 client 快照校验。
3. 删除当前设备原实现没有可靠更新激活 ID，已改为一次性提交列表与下一激活设备。
4. TLS 拨号失败时原始 socket 可能未释放，已增加失败清理。
5. 证书指纹不符原本可能落入普通重连分支，已识别为不可恢复错误。

未修改 server、Mac Python 客户端、Tauri 客户端和 v3 协议；本次修复范围限定为 Android 连接链路及其必要文档。

## 4. 验证结果

- `cd android-app && ./gradlew clean assembleDebug`：通过。
- `cd server && go test ./... -count=1`：通过。
- `python3 -m pytest mac-app/tests/ -q`：通过。
- `git diff --check`：通过。
- `adb devices -l`：没有连接 Android 实体设备，因此没有完成真实权限弹窗、前台服务、TLS 公网连接和音频推流实测。

构建出现的提示是当前 Android Gradle Plugin 对 `compileSdk = 35` 的建议警告，不影响本次构建通过。

## 5. 用户验收

安装 `android-app/app/build/outputs/apk/debug/app-debug.apk` 后，先确保 Mac Tauri 已显示在线并显示配对秘密，再在 Android 设置中导入 `rv://服务器IP:9432`、添加该秘密并返回主界面。主界面应自动显示“连接中…”或“等待 Mac 上线…”。如果失败，状态条应显示具体的网络、TLS、认证或麦克风错误。
