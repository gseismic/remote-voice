# PLAN-042 Mac 菜单栏支持

- 基线 `4d0e823`
- 时间 2026-11-25（Asia/Shanghai）
- 设计 [macos-menu-bar-20261125-overview.md](../design/macos-menu-bar-20261125-overview.md)

## 实施

1. 在 macOS 目标启用 Tauri 托盘能力，使用适配系统浅色和深色菜单栏的麦克风图标。注册状态项、显示窗口和退出动作。
2. 复用 `AppController` 的状态和连接生命周期。仅在菜单状态文案变化时调度原生更新，由主线程读取最新状态。关闭主窗口时隐藏窗口，菜单和 Dock 复用窗口恢复逻辑。
3. 在应用退出事件中停止中继、结束音频输出并释放模拟 Fn。验证关闭窗口、真正退出和菜单栏创建失败三条路径的行为。更新 Mac 使用说明。

## 验证

1. 自查窗口焦点和退出事件、托盘资源持有、连接线程退出与主线程菜单更新的顺序。
2. 运行 Rust 格式检查、测试、Clippy、前端构建和 `git diff --check`。
3. 在目标 Mac 的临时目录构建应用，验证窗口关闭后仍在线、菜单和 Dock 能恢复窗口，退出动作能结束进程。用本地中继验证菜单状态与后台传音，记录真实验收范围。
4. 写实施结果，追加 `docs/dev/INDEX.md`，提交并推送。
