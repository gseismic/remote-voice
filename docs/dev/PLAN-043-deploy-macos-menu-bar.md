# PLAN-043 部署 Mac 菜单栏版本

- 基线 `1980538`
- 时间 2026-11-25（Asia/Shanghai）

用户点击关闭按钮后，没有看到菜单栏入口。目标 Mac 的 `/Applications/Remote Voice.app` 仍是 2026-11-24 的安装包，签名摘要为 `a210c327…`，二进制中没有菜单栏动作。上一轮在临时应用包完成验证。 [PLAN-042 验证结果](PLAN-042-macos-menu-bar-OUTCOME.md)

1. 在 Mac 上从提交 `1980538` 构建发布包，用锁定依赖和现有编译缓存。校验签名、菜单栏动作和二进制摘要。
2. 将原安装包压缩备份并验证压缩包。安装新包前核对进程状态，必要时正常退出应用。按原路径安装并启动新版，检查运行的二进制与构建产物一致。安装或启动失败时恢复原包。
3. 在正式安装版验证红色关闭按钮、同一进程存活、菜单栏状态和恢复窗口。核对中继连接与 Fn 授权状态。
4. 记录结果，更新计划索引，提交并推送。
