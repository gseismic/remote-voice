交互行为说明（与代码一致）：
  • 主界面仅一个必输项：连接密码（即三端共享 token 原文）。点「生成」产生 28 位随机强密码（base58 字母表，剔除易混淆字符，约 163bit）。
  • 运行期间禁用「开始推流」（灰色），仅在 未启动/错误 状态可点。
  • 状态栏着色规则（点击上方芯片演示）：绿 #2E7D32=推流中（附加“已发送 N 帧”实时计数）；蓝 #1565C0=连接中/等待 Mac 上线；红 #C62828=错误；灰 #8A8A8A=停止。
  • 设置页服务器地址已预置默认值 43.139.226.138:9432；指纹必填（缺失时主界面点开始会提示并自动跳转设置页）。
  • 导入配置串格式 rv://host[:port]?t=密码&f=指纹，由 relay 启动横幅直接打印；解析成功后同时写入主界面密码、服务器地址与指纹。
  • Action Bar 右上角 ⋮ 设置 进入设置页（菜单资源 menu_main.xml）。
