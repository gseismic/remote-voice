设计要点（详见 docs/design/client-ui-20260826-v2.md）：
  • 双秘密模型：临时秘密为 8 位短码（剔除易混字符），默认重启即换、可勾选保持；永久秘密长期有效。手机用任一即可连接，relay 只存哈希、强制过期，到期不断开已建立会话，仅拒绝新连接。
  • 按住说话（PTT）：按下即采音传输、松开即停（可试按上方按钮）；「免提常开」作为设置项保留会议场景。
  • 多设备单激活：手机可保存多台 Mac，芯片单选，切换即重连；任意时刻只对一台传输。
  • 提示不打扰：成功/失败均为底部滑入的轻提示（可点演示芯片），2.5s 自动消失，不弹窗。
  • 防爆破：按 IP 滑窗限速（5 次失败/分钟）→ 递增锁定（1m/5m/30m），全部落日志；Mac 历史中可见「限速锁定」条目。
  • 零留存：音频全链路内存转发不落盘；日志与历史仅含元数据（时间/IP/时长/字节/结果），不含秘密原文。
与 v1 现状的差异：v1 为 relay 全局共享 token + 手机常开推流；v2 秘密由 Mac 签发（注册制）、交互改 PTT、新增历史与防爆破——属协议 v2 变更，实施需另立计划。
